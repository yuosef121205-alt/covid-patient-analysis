# COVID-19 Patient Data Analysis

Exploratory analysis of 1M+ COVID-19 patient records using Python (Pandas).

## Dataset
COVID-19 patient data from Kaggle. The file is not included because of its size.
COVID-19 patient data from [Kaggle](https://www.kaggle.com/datasets/meirnizri/covid19-dataset). The file is not included because of its size.


## What I Did
- Explored the dataset structure (1,048,575 rows, 21 columns)
- Cleaned unknown codes (98/99) that distort results
- Compared hospitalized vs non-hospitalized patients

## Key Findings
- About 19% of patients were hospitalized
- Hospitalized patients were about 13.5 years older on average
- 51.9% of patients over 60 were hospitalized

## Tools
Python, Pandas, Jupyter Notebook
